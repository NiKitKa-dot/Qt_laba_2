Проект: Дерево объектов QObject
Лабораторная работа №2 по дисциплине «Программирование на C++/Qt».
Тема: Управление памятью и иерархия объектов в Qt.

Описание проекта
Данный проект представляет собой графическое приложение, демонстрирующее механизм работы дерева объектов (QObject Tree) в Qt. Приложение показывает, как родительский объект управляет временем жизни дочерних объектов, а также демонстрирует методы динамического изменения этой иерархии.

Основные возможности программы:

Отслеживание создания и уничтожения объектов. Реализовано через переопределение деструкторов классов-наследников с выводом логов в консоль (qDebug).

Демонстрация автоматического удаления. При нажатии кнопки «Удалить панель» панель и все её дочерние элементы уничтожаются с помощью метода deleteLater().

Смена владельца виджета. Кнопка «Переместить виджет» переносит элемент из одной панели в другую с корректным обновлением Layout'ов.

Отвязка объекта. Кнопка «Демо setParent(nullptr)» открепляет виджет от дерева объектов, делая его независимым.

Безопасность указателей. В коде используются умные указатели QPointer для предотвращения ошибок доступа к удаленным объектам.

Структура проекта
main.cpp — точка входа в приложение, инициализация QApplication и запуск цикла событий.

mainwindow.h / mainwindow.cpp — класс главного окна, настройка интерфейса и логика обработки нажатий на кнопки.

widgets.h — содержит вспомогательные классы (LogLabel, LogButton, LogPanel), которые наследуются от стандартных виджетов и выводят сообщения в консоль при создании и удалении.

QtObjectTree.pro — файл конфигурации сборщика qmake.

Инструкция по сборке и запуску
Для сборки проекта потребуется установленный Qt (версии 5 или 6) и компилятор C++ (GCC, Clang или MinGW).

Сборка через qmake (рекомендуется для Qt Creator):

Откройте файл QtObjectTree.pro в среде Qt Creator.

Выберите необходимый Kit (комплект компилятора).

Нажмите кнопку «Запустить» (зеленый треугольник) или используйте горячие клавиши Ctrl+R.

Сборка через терминал:

Откройте терминал в папке с проектом.

Выполните команды:
qmake QtObjectTree.pro
make -j4
./QtObjectTree

Как проверить работу
Запустите приложение и откройте панель «Вывод приложения» (Application Output) в Qt Creator, чтобы видеть консольные логи.

Нажмите кнопку «Удалить панель». В консоли вы увидите последовательный вызов деструкторов панели и всех виджетов внутри неё.

Попробуйте сначала нажать «Переместить виджет», а затем «Удалить панель». Вы увидите, что перемещенный виджет не удалился вместе с панелью, так как у него сменился родитель.

Нажмите «Демо setParent(nullptr)» и проследите в консоли, как изменилось количество детей у временного объекта.
